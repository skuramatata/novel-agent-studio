# 桌面原型实现记录

日期：2026-09-08。用户明确授权先实现桌面端，并指定仅接入 GLM / MiniMax；允许读取 my-pi-agent 的现有 `.env`，常规实现选择自主确定。

## 已落地范围

四个工作区：创作对话、作者与作品、人物关系、章节阅读。采用深色写作工作室布局。

作者人格、两类文学积累、口癖、比喻引用、禁忌与作品前提可预设、编辑、保存，也可通过结构化对话候选生成。关系图可以拖动、连线、编辑方向和属性；已有正文通过界面与主进程两层限制保持只读。

独立应用位于 `desktop-app/`，作品数据独立保存在应用数据目录。未修改 my-pi-agent 的源码与 `.env`。首轮存储采用原子JSON与备份，尚未实现架构草案中的完整SQLite事务/事实图谱/历史分支，因此不把草案全部标记完成。

## 组件与服务边界

- `src/state/StudioContext.tsx`：跨工作区作品状态、生成状态与串行保存。
- `src/features/`：对话、作者前提、关系图、只读阅读、模型设置；表单草稿与选择保留在所属页面。
- `src/lib/bridge.ts`：类型化桌面调用与显式浏览器演示适配。
- `electron/`：窗口、受限IPC、密钥读取、保存和生成事务协调。
- `runtime/agent.mjs`：上下文、输出契约、有限修复；`providers.mjs`：仅两家官方接口。
- `runtime/schema.mjs`：字段与关系完整性、规划前置、版本冲突、正文只读。
- `runtime/storage.mjs`：文件持久化、备份、损坏检测。

## 已发现的质量差距

真实GLM规划样本在结构校验通过后，仍出现“某人的父亲既失踪又生还”的描述冲突；该候选在桌面中被放弃。说明自动语义连续性尚未解决。提示词已加入生死身份一致性与双时间线定义，但不能据此宣称缺陷消除。

MiniMax首次长规划达到输出上限，未产生采纳结果。依据官方M3接口文档关闭思考模式后继续验证；该调整仅适用于支持关闭思考的M3系列，不强行对M2套用。

## 验收依据

构建与12项领域/接口测试；浏览器交互预览实测作者预设保存、候选采纳、节点拖动、拖拽连线、关系编辑、刷新保持、章节阅读和无编辑入口。真实桌面已启动，GLM/MiniMax密钥连通均成功，实际模型与使用量有记录。详细最终结果见 `desktop-app/VALIDATION.md`。
