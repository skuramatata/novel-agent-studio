# 作者档案与开写规划

状态：已确认的需求与设计草案，2026-09-08。字段和流程尚未实现；下文示例不代表已选定的作者人格或故事。

## 已确认需求

作者需要人格设定、表达习惯和文学积累偏好；能够配置中国古典文学、西方文学等知识背景，以及是否喜欢借作品作比喻。正式起草前需要大纲、人物关系和预计章节安排。

人格描述用于形成一致的创作选择，不作为质量保证。把“博学、深刻、古典气质”写进提示词不能证明模型掌握相应作品，仍须有具体参考材料和评测。

## 分开管理三种声音

| 层级 | 决定什么 | 不能越过的边界 |
|---|---|---|
| 作者档案 | 持续关心的主题、审美判断、取材和表达倾向 | 作者懂某著作不等于角色懂，也不等于每本书都要提它 |
| 作品叙述者 | 第一/第三人称、时代语感、距离、知识范围、是否可靠 | 限知叙述不能为展示作者知识而泄露人物不知道的事实 |
| 角色档案 | 生活经历、教育、欲望、偏见、词汇、口头习惯 | 角色间允许误解、不同知识和声音，不能全部复制作者人格 |

最终应用顺序：正式事实与认知限制优先；然后应用该作品叙述契约、角色声音及场景需求；作者偏好在这些边界内发挥作用。

## 作者档案模板

- 档案标识与版本：
- 人格与内在矛盾：例如习惯寻找理性解释，却会回避某段私人记忆。必须注明如何影响选材、叙述或删改。
- 反复关心的主题：
- 看待人物的态度：同情、疏离、讽刺等，附原创示例。
- 文学积累：按具体领域与作品列出，不把“国学/西方”设成互斥开关。
- 领域条目：领域或作品、偏好强度、可用资料、可借鉴方式、资料可信度。
- 语言习惯：常用词汇层次、句法倾向、停顿、比喻取材、克制程度。
- 口癖：表达形式、适用情绪/场景、不适用场景、近期出现记录；不能规定每章强制出现。
- 引用偏好：是否点名作品、是否化用、是否允许直接引文、密度倾向及用途。
- 避免事项：配示例与理由，区别个人审美与事实硬限制。
- 采纳的原创样稿及拒绝的样稿：附具体反馈；不使用评测保留集。

“国学更丰富”需要细化为经史、诗词、志怪、地方文献等范围；“西方文学更深”也需要细化到小说传统、戏剧、诗歌或具体作品。各领域可以同时存在，偏好强度与资料可信度分开记录。

作品参考条目保存：书名、作者、版本/译本、来源位置、已核验内容、意象或叙事机制、适用场景。直接引文须可核对；无法核实则不冒充原句。化用不得错误署名。作者举例所用书名只有在确认具体版本内容后才作为知识证据。

## 将人格变成可观察行为

示例人格：重视地方文献，观察细密，表达克制，容易怀疑记录的完整性。

对应行为：写档案场景时关注页码、笔迹和缺页；人物面对异常先比对记录；比喻优先从人物当下能感知的事物中选择。该偏好不能让每章都有缺页，也不能把一名没有识字背景的角色写成文献研究者。

表达习惯应有触发条件与变化。例如角色在犹疑时习惯先否定再修正，可体现在措辞和行动上；不应机械重复固定句子。章节间统计重复只用于提示审稿，不设置普适禁词率或比喻配额。

## 开写前的规划包

| 产物 | 至少包含 |
|---|---|
| 创作简报 | 题材、读者体验、主题问题、核心异常、故事规模、作者档案版本 |
| 故事总纲 | 主角欲望、阻碍、因果主线、重大转折、暂定结局与代价 |
| 世界与真相底稿 | 已定事实、未知事项、作者知道但暂不揭示的真相 |
| 人物卡 | 目标、恐惧、资源、矛盾、知识边界、声音、关键变化 |
| 人物关系 | 双向看法、利益/情感/秘密、变化事件、开始与结束状态 |
| 章节计划 | 预计总字数区间、每章长度区间、章节数估计、各章目的与变化 |
| 双时间线 | 事件发生顺序、叙述顺序及映射 |
| 伏笔与揭示表 | 首次出现、允许解释的时点、误导依据、计划兑现位置 |
| 近期场景卡 | 视角、目标、阻碍、行动、已知信息、允许新增信息、结束状态 |

章节数由篇幅估计与事件拆分共同约束。仅作计算示例：目标约6万字、每章约3000字，初估约20章；这不是本项目已选规模。以事件变化检查是否需要合并/拆章，不为填够数量增加无效情节。

全书总纲与每章粗纲先有；临近写作的章节再细化到场景，后段允许低确定度与占位问题。暂定结局须说明局部冲突如何收束及哪些未知有意保留，不能把所有缺失都叫留白。

## 准备状态与变更

规划包状态：draft → ready → superseded。进入 ready 需要检查必要内容、事实冲突、因果缺口、角色行动理由、视角与揭示约束。正式作品由作者采纳规划版本后开始正文；独立实验分支可按已有自动采纳配置运行。不要为每一个字段单独询问确认。

明确的片段实验可以只提供最小场景计划，不要求生成整本书；必须记录任务模式，不能把片段实验当正式章节绕过准备检查。

每次生成绑定 authorProfileVersion、planVersion、baseRevision。写作中提出的转折或关系变化形成规划变更：列出受影响章节、人物关系和伏笔，再生成新计划版本。已写正文不静默跟随新大纲重写。

关系用有方向的记录表达：A信任B不代表B信任A。每条关系记录来源事件和阶段，必要时把“公开身份”和“真实联系”分开，并标注角色和读者的知情情况。

## 下一轮应加入的验证

- 同一场景换作者档案，取材与表达应可区分，事实和事件保持。
- 同一作者下两个角色的知识、关注点和口癖不能趋同。
- 提供不可靠的作品引文时，系统不得冒充核验通过。
- 连续多章保持声音，但不能每章重复口癖或作品比喻。
- 缺总纲、人物关系或章节计划的正式写作请求，应先补规划；片段实验按其最小输入处理。
- 改动人物关系后，识别关联章节与伏笔；只调整预计章节数不能自动修改正式正文。
