# 恐怖小说创作 Agent：能力边界

状态：首轮设计草案，2026-09-08。本文中的技术方案和数值门槛是待实验验证的建议，不代表已实现能力。

## 已确认的目标

主要目标是建立并验证足够强的小说创作 Agent；恐怖小说是首个领域，以洛夫克拉夫特风格为主。不以尽快写出一本小说或签约变现倒推开发取舍。允许先建设 Agent，再正式创作小说；开发中仍需要原创片段和修改任务作为评测材料。

独立建设小说领域模型、流程和评估体系；选择性复用 my-pi-agent 的通用能力。第一阶段交付能力定义、评测种子和架构审计，随后进入运行时接入与基线实验。产品名、独立仓库名称、界面形式、模型和调用预算尚未确定。本轮资料暂存在当前目录。

## 可验收的能力

| 能力 | 输入 | 输出 | 失败的具体表现 |
|---|---|---|---|
| 故事设计 | 情绪目标、人物目标、核心异常 | 因果时间线、叙述时间线、揭示计划 | 为反转新增无依据的事实；人物无理由继续冒险 |
| 受约束创作 | 场景任务、可用事实、视角、字数 | 场景草稿及候选新事实 | 偷看未公开真相；把怀疑写成事实；重复设定解释 |
| 连续性 | 正式设定、已采纳章节、角色认知 | 带出处的问题与候选修订 | 人物失忆、提前知情、地点/时间/物件矛盾 |
| 全局修改 | 变更要求、基础版本、章节依赖 | 影响清单、修订版本、未解决项 | 漏改关联段落；扩大修改；覆盖作者新改动 |
| 恐怖效果 | 目标情绪、正文 | 有具体段落证据的诊断 | 仅统计形容词；用模型高分代替阅读效果 |
| 文风控制 | 作品风格、人物声音、原文 | 有证据的局部修订与保留理由 | 模板化、过度解释、人物同声；润色损失事实或个性 |
| 可靠执行 | 请求、状态版本、预算 | 可追踪运行记录与候选产物 | 重试重复采纳、失败冒充成功、预算失控 |

风格暂操作化为：可信日常、逐渐动摇的解释、有限视角、发现的代价、选择性细节和残余未知。这是本项目的创作约束草案，不是对所有洛夫克拉夫特作品的统一定义。不得把关键词命中当作风格质量。

## 作者与 Agent 的分工

Agent 可自主规划、起草、检查、提出修订并在预算内迭代；正式作品的设定和正文由作者采纳后生效。实验用作品可在显式隔离的运行分支自动采纳，以测试长程能力。两种模式必须写入运行记录，不能共用正式作品的写入目标。

首阶段采用单 Agent 分阶段工作；规划、写作、审稿是职责，不预设必须使用多个 Agent。将增加角色、检索或反思视为实验变量。

## 范围

第一阶段先支持单用户、本地作品、中文输出、场景与小故事单元、JSON/Markdown 导入导出。架构保留跨章节状态和版本关系，不以首批短样本宣称长篇能力。

后续由评测决定：多 Agent、向量检索、独立编辑器、自动经验学习。公共投稿、账号系统、协作平台、计费和自动发布尚不属于当前交付。

## 成功证据

相同输入下，相比直接调用模型和仅增加风格提示词，有可重复的硬约束改善、修改准确性改善和人工盲评收益，并报告额外调用、耗时和成本。失败必须能归因到上下文选择、计划、生成、检查或状态提交，不能统一归为模型不够好。

## 核心补充：减少 AI 味

已确认这是关键能力。具体诊断、风格档案、局部修订和反过度纠正评测见 [文风与AI味控制](style-and-ai-pattern-control.md)。目标是自然且有辨识度的作品声音，不以文本来源检测分数验收。

## 核心补充：作者档案与规划先行

已确认作者人格、表达习惯、文学积累和引用偏好需要配置，正式正文前应有大纲、人物关系和预计章节。具体字段、叙述者/角色边界及规划变更见 [作者档案与开写规划](author-profile-and-planning.md)。
